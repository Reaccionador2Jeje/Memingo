## 3. Guiones para videos / Video scripts

Keep each short video focused on one real feature. Record the actual terminal or editor; never fake output.

### Video 1 — What is Memingo? (20–30 seconds)

**Hook (0–4s):** “¿Y si un lenguaje de programación hablara internet?”

**Demo (4–18s):** Show this example in a real editor:

~~~mgo
vibe name = "Memingo"
spill "Hello " + name

when 8 > 3 {
    spill "this is based"
} nah {
    spill "that's cringe"
}
~~~

Run it with the documented command for the current installation and show the real output.

**Close (18–30s):** “Esto es Memingo: sintaxis con personalidad y herramientas para crear software. Pruébalo en GitHub.”

On-screen links: website and repository.

### Video 2 — Meet MGOA (20–30 seconds)

**Hook:** “Los memes también necesitan paquetes.”

Show actual MGOA commands from the current CLI help or guide: search, info, install, list, and remove. Use a package that exists in the registry and verify the result before recording.

**Close:** “Descubre MGOA en Memingo. Código abierto, herramientas reales.”

### Video 3 — Build something real (30–45 seconds)

Choose one small example already present in the repository, such as a working project or HTTP API example. Show:
1. The source file.
2. The exact command used.
3. The real result in the terminal or browser.
4. The repository link.

Do not describe a prototype as production-ready. Mention limitations honestly.

## 6. Reglas de comunidad y confianza / Community and trust rules

1. Be welcoming to beginners and respectful in technical discussions.
2. Criticism is welcome; explain the issue and, when possible, provide a reproducible example.
3. Do not spam other communities or repeatedly post without permission.
4. Never buy stars, followers, downloads, reviews, or engagement.
5. Never claim Memingo is safer or faster than another language without reproducible evidence.
6. Clearly label experimental, incomplete, or platform-limited features.
7. Do not publish secrets, access tokens, private data, or other people's work without permission.
8. Keep the project open to contributors regardless of experience or location.

| Projects made with Memingo | Practical adoption |

- Qué se publicó / What was published:
