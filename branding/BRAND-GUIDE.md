# Memingo Brand Kit

## Primary mark

Use `memingo-icon.svg` for applications, avatars, extension packages, installers and favicons.
Use `memingo-logo.svg` for banners and websites where a wordmark is useful.
Use `memingo-monochrome.svg` for engraving, monochrome UI and small print.

## Colors

- Yellow: `#FFCF3A`
- Ink: `#171717`
- Meme red: `#EF4D3F`
- Paper: `#F4F1E8`
- White: `#FFFEF9`
- Success green: `#7ED957`

## Clear space

Keep a clear area equal to one eye circle around the icon. Do not stretch, recolor or rotate the primary mark.

## Services

Use the same icon in the website, VS Code extension, package manager, CLI launcher, server launcher and desktop installers. The icon remains square with a 28-unit corner radius for 160x160 artwork.
