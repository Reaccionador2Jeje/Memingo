# Changelog

## 0.2.0

- Added objects, property and index access.
- Added JSON, environment, HTTP, collection, and randomness helpers.
- Added `memingo fmt` and `mgoa` workflows.
- Improved CLI output and cross-platform commands.

## 0.1.0

- Initial Memingo language support.
- Added `.mgo` syntax highlighting and language configuration.
- Added snippets for variables, rituals, conditions and loops.
- Added commands to run files, create projects, open the REPL and serve directories.
