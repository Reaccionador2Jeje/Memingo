MEMINGO 0.2 · LINUX

Instala Memingo.
Code the bit.

Instala el lenguaje y su gestor de paquetes mgoa desde los repositorios oficiales firmados de Memingo.

Debian / Ubuntu · APT Fedora · DNF

Debian y Ubuntu (APT)

Copia el bloque completo en una terminal:

sudo apt-get update
sudo apt-get install -y ca-certificates curl

curl -fsSLo /tmp/memingo-archive-keyring.asc \
  https://reaccionador2jeje.github.io/Memingo/linux/memingo.asc
sudo install -D -m 0644 /tmp/memingo-archive-keyring.asc \
  /usr/share/keyrings/memingo-archive-keyring.asc

echo "deb [signed-by=/usr/share/keyrings/memingo-archive-keyring.asc] https://reaccionador2jeje.github.io/Memingo/linux/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/memingo.list

sudo apt-get update
sudo apt-get install memingo

Verifica los comandos:

memingo --version
mgoa --version

APT valida la firma del repositorio con la clave indicada en signed-by.

Fedora y sistemas compatibles con DNF

Crea la configuración oficial del repositorio:

sudo tee /etc/yum.repos.d/memingo.repo >/dev/null <<'EOF'
[memingo]
name=Memingo
baseurl=https://reaccionador2jeje.github.io/Memingo/linux/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://reaccionador2jeje.github.io/Memingo/linux/memingo.asc
EOF

Instala y comprueba:

sudo dnf makecache
sudo dnf install memingo
memingo --version
mgoa --version

DNF puede pedir confirmación para importar la clave pública. Comprueba que el origen mostrado sea el repositorio oficial de Memingo antes de aceptar.

La configuración mantiene activadas tanto la comprobación de firmas de paquetes como la firma de los metadatos.

Requisito: Memingo necesita Python 3.10 o posterior. El gestor de paquetes instala la dependencia declarada cuando está disponible en los repositorios de tu distribución.

¿Necesitas desinstalar?

Debian / Ubuntu:

sudo apt-get remove memingo
sudo rm -f /etc/apt/sources.list.d/memingo.list
sudo rm -f /usr/share/keyrings/memingo-archive-keyring.asc
sudo apt-get update

Fedora / DNF:

sudo dnf remove memingo
sudo rm -f /etc/yum.repos.d/memingo.repo
sudo dnf clean all

Los proyectos que hayas creado en tus carpetas personales no se eliminan al desinstalar el paquete.

Solución de problemas

  • No se encuentra el paquete: revisa la URL del repositorio y actualiza la caché con apt-get update o dnf makecache.
  • Error de firma: comprueba que descargaste la clave pública desde el sitio oficial y que la verificación de firmas sigue activada. No desactives las comprobaciones para saltarte el error.
  • Falta Python: instala Python 3.10 o posterior desde los repositorios oficiales de tu distribución.
  • No aparece el comando: abre una terminal nueva y ejecuta command -v memingo y command -v mgoa.
