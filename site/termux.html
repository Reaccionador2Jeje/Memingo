ANDROID / GUÍA DE INSTALACIÓN

Memingo en
Termux.

Instala el lenguaje y sus dos comandos —memingo y mgoa— directamente en Android. No necesitas root ni una computadora.

Importante: Termux tiene su propio entorno de paquetes. No uses apt install memingo: los repositorios APT de Debian/Ubuntu y RPM de Fedora no son los repositorios de Termux. Esta guía usa el instalador compatible con Android.

PASO 01

Prepara Termux

Abre Termux y actualiza sus paquetes. Después instala Git y Python:

pkg update
pkg install -y git python

PASO 02

Descarga Memingo

Clona el repositorio que contiene el instalador Termux y entra en la carpeta:

git clone -b feat/arch-aur-packaging https://github.com/Reaccionador2Jeje/Memingo.git
cd Memingo
Nota sobre la versión: mientras el soporte Termux se encuentre en la rama de integración, usa el comando anterior con -b feat/arch-aur-packaging. Cuando esos cambios se integren en la rama principal, la guía se actualizará para usar la descarga normal.

PASO 03

Ejecuta el instalador

El instalador detecta Termux automáticamente y coloca los comandos en $PREFIX/bin:

sh scripts/install.sh
hash -r

PASO 04

Comprueba que funciona

Ejecuta ambos comandos para comprobar la instalación:

memingo --version
mgoa --version

¡Listo! Ya puedes ejecutar Memingo y usar su gestor de paquetes desde Termux.

MANTENIMIENTO

Actualizar Memingo

Entra en la carpeta que clonaste y vuelve a ejecutar el instalador después de descargar los cambios:

cd Memingo
git pull
sh scripts/install.sh
hash -r

DESINSTALACIÓN

Quitar Memingo

Desde la carpeta del repositorio ejecuta:

sh scripts/uninstall.sh

Esto elimina los comandos y el runtime instalado de Memingo; no borra tus proyectos personales.

AYUDA

¿El comando no aparece?

Actualiza la caché de comandos de la terminal y comprueba que Termux tiene configurada su carpeta de ejecutables:

hash -r
echo "$PREFIX/bin"
command -v memingo
command -v mgoa

Si sigue sin funcionar, revisa que pkg install -y git python terminó correctamente y vuelve a ejecutar sh scripts/install.sh.
